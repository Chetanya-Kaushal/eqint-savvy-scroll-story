EQInt Savvy Your Oracle Copilot

A frameless, always-on-top Electron overlay that reads your Oracle Fusion HCM pages via OCR, answers questions with a local LLM, runs payroll reconciliation across 4 modes, generates BIP reports, tracks 15 analytics dimensions, and executes 30+ HCM commands — all from your desktop. Payroll Reconciliation

Policy Rules
Meet Oracle Data

Four reconciliation modes powered by a Python backend engine. Upload Excel files (Activity/Register + Costing) for offline comparison, or connect live to Oracle BIP to fetch Element Result and Costing Detail reports automatically. The Live Flow Reconciliation resolves payroll flows by name, fetches reports in real-time, and builds a verified Excel workbook with matched/mismatched lines. BIP Catalog Recon browses your Oracle BIP folders, lets you pick reports, and reconciles by date range. Oracle Recon discovers available payroll periods, lists flows, and reconciles on selection. Natural language policy rules (parsed via LLM) define tolerance thresholds per element — "tolerance of 0.01 for Basic Salary" — and flag violations automatically. The recon chat assistant maintains session state for follow-up commands like "show variances", "fix mismatch", or "download excel".

Built-in Tools

Every Tool,
One Overlay

01
BIP Reports
Browse, generate, and export BI Publisher reports directly from the overlay. A local TypeScript BIP server (port 3000) proxies Oracle BI Publisher SOAP/REST calls. The main process spawns it via npx tsx, and the renderer fetches report catalogs, binds parameters, and downloads XML/PDF/Excel outputs. Supports both standard and custom report folders with automatic folder discovery.
TypeScript + SOAP/REST
02
Page Reader (OCR)
Captures your active Oracle Fusion screen using Electron's desktopCapturer API, runs Tesseract.js OCR with eng.traineddata, and feeds the extracted text to the AI chat. The page reader detects the foreground window, captures a screenshot, processes it through the OCR pipeline, and injects the result as chat context — letting Savvy "see" what's on your screen without manual input. Supports multi-monitor capture.
Tesseract.js + desktopCapturer
03
Local Auth Security
Every installation generates a unique 32-byte pairing token stored in userData with 0o600 permissions. The backend's LocalTokenMiddleware validates X-Local-Token headers on every request, ensuring only this specific desktop app instance can communicate with the local API server. Tokens are persisted via crypto.randomBytes and survive app restarts. On Windows, SafeStorage encrypts via DPAPI; on macOS via Keychain.
Crypto + DPAPI/Keychain
04
SSO / OpenID Connect
Enterprise SSO login via OpenID Connect (openid-client library). Implements the PKCE (Proof Key for Code Exchange) flow for secure authorization without client secrets. Supports tenant-based configuration via policy-config.js, automatic token refresh before expiry, and integration with Oracle Identity Cloud Service. Tokens are stored in the OS keychain via keytar for zero-plaintext persistence.
OIDC + PKCE + keytar
05
Cursor Awareness
Real-time cursor position tracking via Electron's screen API. The describeCursorRegion module divides the screen into a 3x3 grid and detects which region you're hovering over, providing context-aware suggestions based on where your cursor is on the Oracle page. Uses screen.getCursorScreenPoint() for precise coordinates across multi-monitor setups. The overlay window follows the cursor region for optimal positioning.
3x3 Grid + Multi-Monitor
06
Auto-Update
Built-in auto-updater via electron-updater with NSIS installer and portable build targets. Checks a generic update server on launch, shows native desktop notifications for available updates, supports delta downloads, and handles both Windows installer (.exe) and portable executables. The afterSign hook handles macOS notarization with entitlements for hardened runtime. Build pipeline via electron-builder with code signing.
electron-updater + NSIS
07
Bubble Mode
Collapse the entire overlay into a floating 80x80px moon icon with CSS-animated clouds and sparkles. The bubble uses backdrop-filter blur, gradient backgrounds, and keyframe animations for the glow effect. Click to expand back to full overlay. The bubble sits at the screen corner with always-on-top positioning, consuming zero screen real estate while remaining instantly accessible. State is preserved across collapse/expand cycles.
CSS Animations + State Preservation
08
Voice I/O
Dual voice system: Web Speech API for browser-native ASR (speech recognition) and TTS (text-to-speech), with API-powered fallback via Azure Neural TTS (en-US-AvaNeural default). Voice selection with configurable rate/pitch/volume. Sentence-by-sentence streaming for natural pauses. The voice toggle persists across sessions. Supports hands-free queries — speak your HCM question and get an audio response.
Web Speech + Azure Neural TTS
Architecture

Built on Three Layers

Electron main process, preload bridge, and renderer — each isolated, each secure. The Python backend handles Oracle communication while TypeScript servers power BIP and dashboards. Every process is spawned, monitored, and killed independently.

Main Process
Electron main: window management (frameless, always-on-top, resizable overlay), system tray with context menu, IPC handlers for file dialogs/native dialogs, backend server spawning (Python uvicorn on port 8080), BIP server (TypeScript on port 3000), dashboard server (port 3001). Handles auto-updater, screen capture, secure storage (keytar + safeStorage), SSO auth (OpenID Connect PKCE), policy config loading (platform-specific paths), cursor region detection, and telemetry with PII scrubbing.
Preload Bridge
Context-isolated bridge via contextBridge.exposeInMainWorld. Exposes window.electronAPI (file I/O, dialogs, clipboard, shell) and window.savvy APIs (HCM endpoints, settings). Sandbox: true, nodeIntegration: false, contextIsolation: true. No direct DOM access from renderer. All IPC is serialized — no shared memory between main and renderer processes.
Renderer (UI)
overlay.html + app.js + renderer modules. Chat engine with local command processing (30+ actions), streaming responses, abort control. Dashboard with Chart.js visualizations. 15 analytics tabs with parallel Oracle API fetch. Payroll reconciliation with 4 modes. BIP report browser. Settings page with Ollama/Oracle config. Bubble mode with CSS animations. Voice I/O via Web Speech API. Page reader via Tesseract.js OCR. Worker profile expansion/flatten logic. Person query parsing with self-reference detection.
Backend (Python)
FastAPI + uvicorn on port 8080. Oracle HCM REST proxy with endpoint scoping (person-scoped vs reference-only paths). Analytics aggregation across 13+ endpoints. Policy rule parsing via Ollama LLM. Payroll reconciliation engine with Excel generation. Enhanced chat endpoint with context injection. Reconciliation chat with session state. Code execution sandbox. Voice synthesis API. Telemetry with PII field scrubbing. LocalTokenMiddleware for IPC security.

Keytar + SafeStorage
OS-native credential storage. Keytar uses system keychain (macOS Keychain, Windows Credential Vault, Linux Secret Service) for Oracle passwords and SSO tokens. SafeStorage encrypts session tokens via Electron's safeStorage API (DPAPI on Windows, Keychain on macOS). Token store persists {sessionToken, ssoIdToken} under service "EQInt Savvy" with account "auth-tokens". Zero plaintext on disk.
